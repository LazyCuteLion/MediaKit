# MediaKit 着色器源生成器 · 使用说明

`MediaKit.ShaderEffectGenerators` 是一个 Roslyn 增量源生成器（`netstandard2.0`，不引用任何 UI 框架，仅输出源代码字符串）。它把着色器源文件作为 `AdditionalFiles` 读入，依据文件内的**注释标记**为消费方项目生成对应的 C# 效果类。

生成器 DLL 本身不依赖 WPF / Avalonia，生成的代码编译进消费方项目，因此**同一个生成器可按扩展名分派到多个平台**。

---

## 1. 入口与扩展名分派

入口 [ShaderEffectGenerator](file:///d:/Desktop/MediaKit/MediaKit.ShaderEffectGenerators/ShaderEffectGenerator.cs) 只做一件事：按文件扩展名把着色器文件路由到对应的 emitter。

| 扩展名 | 平台 | Emitter | 目标命名空间 |
|--------|------|---------|--------------|
| `.sksl` | Avalonia | [AvaloniaEmitter](file:///d:/Desktop/MediaKit/MediaKit.ShaderEffectGenerators/AvaloniaEmitter.cs) | `MediaKit.Avalonia.Effects` |
| `.fx`   | WPF | [WpfEmitter](file:///d:/Desktop/MediaKit/MediaKit.ShaderEffectGenerators/WpfEmitter.cs) | `MediaKit.WPF.Effects` |
| `.hlsl` | WinUI（预留） | — | — |

**核心设计理念（三维度解耦）**：标记语法让 **C# API 形态**与 **着色器源码声明**彻底解耦——
- **命名规范解耦**：着色器变量用惯用命名（HLSL camelCase / SkSL uniform 名），C# 端得到规范的 PascalCase 属性名；
- **语义覆盖**：同一底层类型（如 `float4`）可能是颜色、坐标、四元数，标记可显式指定 CLR 语义类型；
- **默认值对齐**：标记声明的默认值编译成与着色器初值语义一致的表达式，保证 C# 默认值 = 着色器默认值。

## 2. WPF（`.fx`）标记语法

### 2.1 消费方接入

`MediaKit.WPF.csproj` 需要：

```xml
<ItemGroup>
  <AdditionalFiles Include="Shaders\*.fx" />
  <ProjectReference Include="..\MediaKit.ShaderEffectGenerators\MediaKit.ShaderEffectGenerators.csproj"
                    OutputItemType="Analyzer" ReferenceOutputAssembly="false" />
</ItemGroup>
```

> ⚠️ `.fx` 文件必须以 **无 BOM 的 UTF-8** 保存，否则 `fxc.exe` 会报 `error X3000: Illegal character in shader file (1,1)`（有时连锁误报为 `X3003 redefinition`）。用编辑器修改后若出现该错误，需剥离文件头部的 `EF BB BF`，再另存为无 BOM UTF-8。

### 2.2 效果类标记：`// @effect`

一个 `.fx` 文件用 `// @effect` 声明效果类（缺省时整文件被忽略）。**标记值**决定生成形态——保留关键词 `default` 表示「仅注册」，其余值（含空）表示「生成类」：

| 写法 | 生成形态 | Attach / Detach | 构造钩子 | 适用场景 |
|------|----------|-----------------|----------|----------|
| `// @effect` / `// @effect: Name` | `public partial class`（类名 = `Name`，缺省 `{文件名}Effect`） | 由**手写 partial** 提供 | 生成 `partial void OnConstructed()` | 有交互 / 运行时计算 / 需要手写逻辑的效果 |
| `// @effect: default` | `public sealed class`（类名恒为 `{文件名}Effect`） | **内联生成**（自包含） | 无 | 无交互的纯参数着色器，开箱即用 |

- 保留关键词 **`default`**（大小写不敏感）= 仅注册模式：生成自包含 sealed 类，无需手写 partial。
- 其余任何值（含空标记）都生成 `partial` 类；显式值即类名，缺省回退 `{文件名}Effect`（文件名首字母自动大写，如 `bg1` → `Bg1Effect`）。
- 多个 `.fx` 产出同名类会触发编译错误 **WPFSHADER001**。

### 2.3 动画标记：`// @animate`

配合 `time` 保留名寄存器（见 2.6）使用：

- 对 `@effect: default`（仅注册）类：Attach 时自动挂 `CompositionTarget.Rendering`，每帧把 `(now - startTime).TotalSeconds` 推送到 `Time`，Detach 时摘除——**无需任何手写代码**。
- 对普通 `@effect`（生成类）：仅作为语义标记；动画循环与 `Time` 的驱动仍由手写 partial 负责（生成器不为它内联渲染循环）。

### 2.4 `// @property` —— 标记寄存器暴露为公共依赖属性

**三段式语法，三段均可省略：**

```
// @property[: <属性名>] [: <CLR类型>] [= <默认值>]
```

标记必须紧贴在一条**常量寄存器声明行**之前（两者之间允许有其它注释行 / 空行，但不能夹其它代码行）。解析见 [ParseProperty](file:///d:/Desktop/MediaKit/MediaKit.ShaderEffectGenerators/WpfEmitter.cs)。

| 字段 | 缺省来源 | 说明 |
|------|----------|------|
| 属性名 | HLSL 变量名首字母大写（`ripple0 → Ripple0`、`aspectRatio → AspectRatio`） | 生成的公共依赖属性名，与着色器变量名解耦 |
| CLR 类型 | HLSL 类型映射（见 2.5） | 覆盖默认映射，用于表达 `float4` 到底是 `Color` 还是 `Point4D` 等语义 |
| 默认值 | 寄存器行的初始化式 `= float4(...)` | 生成依赖属性默认值 |

三种典型写法：

```hlsl
// @property                                  裸标记：全部走缺省
float3 ripple0 : register(c3);                → Ripple0, Vector3D, (0,0,0)

// @property: Rows = 1.0                      显式名 + 默认值
float rows : register(c0) = float(1.0);       → Rows, double, 1.0

// @property: SpacingColor : Color = Transparent   显式名 + 类型 + 默认值
float4 spacingColor : register(c3) = float4(0,0,0,0);  → SpacingColor, Color, Colors.Transparent
```

> 属性名 / 类型 / 默认值的**优先级**均为「标记显式 > 缺省来源」。裸标记等价于让三段全部回退到缺省，因此只要一句 `// @property` 即可自动生成 DP。

### 2.5 HLSL → CLR 默认类型映射

未显式指定 CLR 类型时，[MapHlslToClr](file:///d:/Desktop/MediaKit/MediaKit.ShaderEffectGenerators/WpfEmitter.cs) 按下表映射（默认取**数值打包语义**）：

| HLSL 类型 | 默认 CLR 类型 | 可覆盖为 |
|-----------|--------------|----------|
| `float`  | `double`   | — |
| `float2` | `Point`    | — |
| `float3` | `Vector3D` | — |
| `float4` | `Point4D`  | `Color`（颜色语义时须显式写 `: Color`） |

> ⚠️ `float4` 默认映射为 **Point4D**（坐标 / 四元数 / 参数打包语义）。若某寄存器实际是颜色（如 `spacingColor`），**必须显式标注 `: Color`**，否则会得到 `Point4D` 而非 `Color`。

`PixelShaderConstantCallback` 把 CLR 值打包回 float 推送到寄存器：`double→float`、`Point→float2`、`Vector3D→float3`、`Color`/`Point4D→float4`。

### 2.6 保留名 `time` 与采样器

- **`time` 寄存器**（`float time : register(cN);`）：即使带 `@property` 也**不生成同名公共属性**，而是单独生成 `Time`(double) DP（携带该寄存器的 `PixelShaderConstantCallback`），供 `@animate` 自动循环或手写动画驱动。
- **采样器行** `sampler2D input : register(s0);`：自动生成 `Input` 采样器依赖属性（`RegisterPixelShaderSamplerProperty`），取第一个采样器的寄存器号，无需标记。
- **未标记的常量寄存器**（如 Tile 的 `spacing`(c2)、`aspectRatio`(c4)）：**不暴露为公共 API**，交由手写 `partial` 处理（打包属性、运行时计算、枚举映射等）。这是「标记驱动、按需暴露」的分工，仅适用于 `@effect`。

### 2.7 默认值表达式规则

见 [GetDefaultExpression](file:///d:/Desktop/MediaKit/MediaKit.ShaderEffectGenerators/WpfEmitter.cs)。数值类型会解析 `floatN(...)` / `float(...)` 包裹、逗号分隔多分量与单值 splat，缺省分量补 `0.0`：

| CLR 类型 | 标记 / 寄存器写法示例 | 生成表达式 | 缺省值 |
|----------|------------------------|------------|--------|
| `double` | `= 1.0` / `= float(2)` | `1.0` / `2.0`（自动补 `.0`、去 `f`） | `0.0` |
| `Color`  | `= Transparent` / `= Red` | `Colors.Transparent` / `Colors.Red` | `Colors.Transparent` |
| `Point`  | `= float2(1, 2)` | `new Point(1.0, 2.0)` | `new Point(0.0, 0.0)` |
| `Vector3D` | `= float3(0.5)`（splat） | `new Vector3D(0.5, 0.5, 0.5)` | `new Vector3D(0.0, 0.0, 0.0)` |
| `Point4D` | `= float4(0.1, 50, 10, 3)` | `new Point4D(0.1, 50.0, 10.0, 3.0)` | `new Point4D(0.0, 0.0, 0.0, 0.0)` |

> `Color` 默认值直接拼 `Colors.{值}`，因此只支持 `Colors` 中的具名颜色（如 `Red`、`Transparent`）。

### 2.8 生成产物结构

对每个效果，[GenerateEffectClass](file:///d:/Desktop/MediaKit/MediaKit.ShaderEffectGenerators/WpfEmitter.cs) 产出 `{ClassName}.g.cs`，包含：

1. `private static readonly PixelShader _shader`（pack URI 指向 `Shaders/Compiled/{文件名}.ps`，程序集名固定 `MediaKit.WPF`）；
2. `Input` 采样器依赖属性（若有采样器）；
3. 每个 `@property` → 一个**公共依赖属性 + CLR 包装属性**，`UIPropertyMetadata` 直接携带 `PixelShaderConstantCallback({寄存器号})`；有 `time` 时额外生成 `Time` DP；
4. `Target` 宿主绑定依赖属性（`FrameworkElement`）+ 生命周期管理（`OnTargetChanged` / `OnTargetLoaded` / `OnTargetUnloaded` + `AttachCore` / `DetachCore` 幂等包装）：**持续监听元素 `Loaded`/`Unloaded` 成对驱动 `Attach`/`Detach`**——元素加载 / 重新父化后加载时 `Attach`，卸载（`Unloaded`，如窗口关闭、TabItem 切走）时自动 `Detach` 清理，换绑 / 置空 `Target` 时摘旧订阅并 `Detach`；
5. 构造函数：设置 `PixelShader`、对各属性 `UpdateShaderValue`；普通 `@effect` 额外调用 `partial void OnConstructed()` 钩子；
6. `@effect: default`（仅注册）内联 `Attach`/`Detach`（`@animate` 时含 `CompositionTarget.Rendering` 循环）；
7. 配套 `[MarkupExtensionReturnType]` 的 `{ClassName}Extension : MarkupExtension`，`ProvideValue` 中把标记目标元素赋给 `Target` 实现自动挂载。

普通 `@effect` 的手写 `partial` 侧负责：未标记寄存器初值推送（在 `OnConstructed` 中）、`Attach`/`Detach` 实现、以及打包 / 计算 / 枚举类属性与交互动画。

> **生命周期与幂等**：手写 `Attach`/`Detach` **只需实现自身的事件订阅 / 资源清理**，无需处理重复调用或卸载时机——生成器用 `_isAttached` 标志的 `AttachCore`/`DetachCore` 保证二者仅在状态翻转时各执行一次，并已挂接元素的 `Loaded`/`Unloaded`。这可避免元素卸载后 `CompositionTarget.Rendering` 等静态事件强引用造成的内存泄漏与持续回调。

> **关键认知**：`@property` 只生成参数依赖属性，**不生成交互或动画逻辑**。像点击涟漪这类交互，必须在手写 partial 里实现事件监听与逐帧驱动。

### 2.9 示例 A：`@effect` + 裸标记 + 手写交互（[Ripple.fx](file:///d:/Desktop/MediaKit/MediaKit.WPF/Shaders/Ripple.fx)）

```hlsl
// @effect: RippleEffect

// @property
float time : register(c0);                                → Time (保留名，单独 DP)
// @property
float aspectRatio : register(c1) = 1.7778;                → AspectRatio, double, 1.7778
// @property
float4 params : register(c2) = float4(0.1, 50.0, 10.0, 3.0); → Params, Point4D
// @property
float3 ripple0 : register(c3);                            → Ripple0, Vector3D, (0,0,0)
// @property
float3 ripple1 : register(c4);                            → Ripple1
// @property
float3 ripple2 : register(c5);                            → Ripple2
// @property
float3 ripple3 : register(c6);                            → Ripple3

sampler2D input : register(s0);                           → Input 采样器 DP
```

生成 `RippleEffect` 的公共属性 `Input / AspectRatio / Params / Ripple0~3 / Time / Target`；手写 [RippleEffect.cs](file:///d:/Desktop/MediaKit/MediaKit.WPF/Effects/RippleEffect.cs) 提供 4 槽环形缓冲的点击交互与逐帧 `Time` 驱动（`duration` 秒内连点可同时并存多圈扩散 / 衰减水波）。

### 2.10 示例 B：`@effect` + 显式命名 + 未标记寄存器（[Tile.fx](file:///d:/Desktop/MediaKit/MediaKit.WPF/Shaders/Tile.fx)）

```hlsl
// @effect: TileEffect
sampler2D input : register(s0);

// @property: Rows = 1.0
float rows : register(c0) = float(1.0);
// @property: Columns = 1.0
float columns : register(c1) = float(1.0);
float2 spacing : register(c2) = float2(0.0, 0.0);      // 未标记：内部 UV 参数，手写处理
// @property: SpacingColor : Color = Transparent
float4 spacingColor : register(c3) = float4(0, 0, 0, 0);
float aspectRatio : register(c4) = float(1.0);          // 未标记：运行时计算，手写处理
```

`TileEffect` 拥有公共属性 `Input / Rows / Columns / SpacingColor(Color) / Target`；`spacing`(c2)、`aspectRatio`(c4) 由 [TileEffect.cs](file:///d:/Desktop/MediaKit/MediaKit.WPF/Effects/TileEffect.cs) 手写 partial 管理。

## 3. Avalonia（`.sksl`）标记语法

Avalonia 端与 WPF **不同**：`.sksl` 的 `@property` 只提供默认值，属性名与类型分别来自 `uniform` 名和 `uniform` 类型。

### 3.1 头部标记

| 标记 | 作用 |
|------|------|
| `// @effect` / `// @effect: ClassName` | 生成强类型效果类（`partial class : ShaderEffect`），缺省 / 空回退 `{文件名}Effect` |
| `// @effect: default` | 仅注册为 `ShaderEffects.{文件名}` 描述符，不生成强类型类 |
| `// @animate` | 标记该效果需要逐帧动画（生成描述符时传 `animate: true`） |
| `// @property: <默认值>` | 紧贴 `uniform` 行，将该 uniform 暴露为公共 `DirectProperty` |

标记值同样以保留关键词 `default` 区分：`@effect: default` 只注册描述符；其余 `@effect` 值（含空）生成强类型效果类。

### 3.2 `@property` + uniform

```glsl
// @property: 0.5
uniform float amplitude;
```

- **属性名**：uniform 名 PascalCase（`amplitude → Amplitude`）；
- **类型**：由 uniform 类型经 [GetCSharpType](file:///d:/Desktop/MediaKit/MediaKit.ShaderEffectGenerators/AvaloniaEmitter.cs) 映射：`float→double`、`float2/3/4→float[]`、`int→int`；
- **默认值**：标记值经 [GetDefaultExpression](file:///d:/Desktop/MediaKit/MediaKit.ShaderEffectGenerators/AvaloniaEmitter.cs) 转换（`float2/3/4` 支持逗号分隔多分量或单值广播）；
- **未标记的 uniform 不暴露**；`iResolution` / `iSourceSize` / `iImage` / `iTime` 为保留 uniform，即使标记也跳过。

### 3.3 生成产物

- 每个 `@effect` → `{ClassName}.g.cs`：`DirectProperty` + 字段 + CLR 属性（setter 中 `SetAndRaise` 后把值推给 `this["uniformName"]`），构造函数注入 `_shaderUri`（`avares://MediaKit.Avalonia/Shaders/{文件名}.sksl`）并初始化各 uniform；
- 全局 `ShaderEffects.g.cs`：把所有效果（生成类的与仅注册的）收口为 `ShaderEffects.{Name}` 静态 `EffectDescriptor`；
- `ShaderEffectAutoRegister.g.cs`：`[ModuleInitializer]` 中自动 `ShaderEffectConverter.Register(...)`。

## 4. 两平台标记语法对照

| 维度 | WPF `.fx` | Avalonia `.sksl` |
|------|-----------|------------------|
| 生成类标记 | `// @effect` / `// @effect: Name` | `// @effect` / `// @effect: Name` |
| 仅注册 / 自包含 | `// @effect: default`（生成 sealed 自包含类） | `// @effect: default`（仅生成描述符） |
| 动画标记 | `// @animate`（配 `time` 保留名，`default` 时内联渲染循环） | `// @animate`（描述符 `animate: true`） |
| 属性标记 | `// @property [:名] [:类型] [=默认]`（三段全可省） | `// @property: 默认值`（仅默认值） |
| 属性名来源 | 标记显式 > 变量名首字母大写 | uniform 名 PascalCase |
| 属性类型来源 | 标记显式 > HLSL 映射（`float4→Point4D`） | uniform 类型映射（`float4→float[]`） |
| 属性系统 | `DependencyProperty` | `DirectProperty` |
| 参数推送 | `PixelShaderConstantCallback` | setter 中 `this["uniform"] = ...` |
| 挂载机制 | `Target` 依赖属性 + MarkupExtension | `EffectDescriptor` + 自动注册 |
| 重复名诊断 | `WPFSHADER001` | `SKSL001` |

## 5. 排错速查

| 现象 | 原因 | 处理 |
|------|------|------|
| `X3000: Illegal character (1,1)` / 连锁 `X3003` | `.fx` 带 UTF-8 BOM | 剥离文件头 `EF BB BF`，另存为无 BOM UTF-8 |
| `WPFSHADER001` / `SKSL001` | 多个文件产出同名效果 | 改 `@effect` 名或文件名 |
| 属性没生成 | `@property` 与寄存器 / uniform 行之间夹了代码行 | 让标记紧贴声明行（中间只允许注释 / 空行） |
| `float4` 属性生成成 `Point4D` 但语义是颜色 | 依赖了 `float4→Point4D` 默认映射 | 显式写 `: Color` 覆盖 |
| 生成了参数属性但交互 / 动画不生效 | `@property` 只生成参数 DP，不生成逻辑 | 普通 `@effect` 需手写 partial 实现交互；纯动画可用 `@effect: default + @animate + time` |
| 生成代码看不到 | `.g.cs` 默认不落盘 | 在 csproj 设 `EmitCompilerGeneratedFiles=true` 查看 |
